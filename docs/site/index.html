From VCF to report, in four stages.

Each variant is annotated in parallel, merged on one transcript, given gene-level evidence, classified, filtered and reported. Nextflow runs it in Docker, Singularity or Podman, on a laptop, a server or a cluster.

  1. 1Preprocessing

    Normalize · GATK filter · Rename

  2. 2Variant-level annotation

    Ensembl VEP with ClinVar, ClinGen and up to 32 plugins · dbNSFP 5.3 · vcf2maf · optional GeneBe · merge · RENOVO 1.5

  3. 3Gene-level annotation

    OMIM · Orphanet · GenCC · HPO · pathways · HPA · constraint · ClinGen · HPO match

  4. 4Classification and report

    ClinVar tiers · PS1/PM5 · optional ACMG · filter · HTML report and MAF

  5. 0Setup, once

    Basic and extended databases, from a pinned YAML manifest, with a setup report

55 of the 67 files in MuSA 1.4's manifest are checked against a pinned checksum. ClinVar's weekly release and ClinGen's live exports change under the same address, so their hashes are recorded rather than checked. Annotation itself runs offline: only setup downloads, and only the optional GeneBe scoring sends variants out.

Three commands to a first report.

  1. Install Nextflow

    Version 25.10 or later, plus Docker, Singularity or Podman.

    curl -s https://get.nextflow.io | bash

  2. Download every database with one command

    Once. Basic mode is ~30 GB and needs no account. Use an absolute path.

    nextflow run davide-scognamiglio/MuSA \ --workflow setup \ --data_dir $PWD/musa_data \ -profile docker

  3. Run the bundled test

    A single-variant VCF, done in a couple of minutes. Then open the report in a browser.

    nextflow run davide-scognamiglio/MuSA \ -profile test,docker \ --data_dir $PWD/musa_data \ --outdir output_test
